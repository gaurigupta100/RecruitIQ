About the Project

Learn about the technology and machine learning pipeline behind ResumeScreen AI.

Project Overview

ResumeScreen AI is an intelligent resume screening system that automates the classification of resumes into 25 distinct job categories. Built as a full-stack Flask application, it combines natural language processing, machine learning, and modern web technologies to deliver instant, actionable insights for recruiters and job seekers alike.

The system extracts text from PDF and DOCX resumes, applies rigorous text preprocessing, classifies the document using a pre-trained Linear SVM model, and enriches results with skills detection, ATS scoring, job recommendations, and downloadable PDF reports.

Dataset

The machine learning model was trained on a comprehensive resume dataset containing thousands of labeled resumes spanning 25 professional categories including Data Science, Python Developer, Java Developer, DevOps Engineer, HR, Sales, and more. Each resume was labeled with its corresponding job category to enable supervised multi-class classification.

Machine Learning Pipeline

1
Text Extraction

Parse PDF (PyMuPDF) and DOCX (python-docx) files to extract raw resume text.

2
Text Preprocessing

Lowercase, remove URLs, punctuation, numbers, stopwords, and normalize whitespace.

3
TF-IDF Vectorization

Transform cleaned text into numerical feature vectors using Term Frequency-Inverse Document Frequency.

4
Linear SVM Classification

Classify the vectorized resume using a Linear Support Vector Machine with one-vs-rest strategy.

5
Confidence Scoring

Compute confidence percentages using decision_function() values normalized via softmax.

TF-IDF

Term Frequency-Inverse Document Frequency (TF-IDF) is a numerical statistic that reflects how important a word is to a document in a collection. It increases proportionally to the number of times a word appears in the document but is offset by the frequency of the word in the corpus, helping to adjust for the fact that some words appear more frequently in general.

Linear SVM

Linear Support Vector Machine (SVM) finds the optimal hyperplane that separates data points of different classes with maximum margin. For multi-class problems, a one-vs-rest strategy trains one classifier per class. LinearSVC is efficient for high-dimensional sparse text data produced by TF-IDF vectorization.
