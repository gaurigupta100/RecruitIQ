# RecruitIQ
🤖 RecruitIQ – AI Resume Analyzer

RecruitIQ is an AI-powered resume analysis system that analyzes resumes, identifies relevant skills, highlights missing skills, and recommends suitable job roles to help candidates understand their career opportunities.

🎯 Problem Statement
Manual resume screening can be time-consuming, and candidates may find it difficult to identify skill gaps and suitable job roles.

💡 Solution
RecruitIQ automates resume analysis using AI and Machine Learning to extract skills, identify missing skills, and recommend relevant job roles based on the candidate's profile.
 ✨ Key Features
- 📄 Resume Analysis
- 🛠️ Skill Extraction
- 🔍 Missing Skills Identification
- 💼 Job Role Recommendations
- 📊 Candidate Profile Analysis
🛠️ Technologies Used
- Python
- Machine Learning
- Streamlit
- Pandas
- NumPy
- Scikit-learn

🧠 AI Model & Integration
The project uses a trained Machine Learning model to analyze resume-related information and support job role recommendations. AI/ML functionality is integrated into the application using Python.
